# 矿物行走者（Mineral Walker）V2.0.1

Minecraft Java 26.2 / Fabric 模组。

## 穿戴方式
- 不注册任何矿物护腿物品。
- 直接使用 Minecraft 原版矿物块物品，穿到玩家装备栏的护腿位置。
- 支持煤炭块、铁块、金块、钻石块、绿宝石块、青金石块、红石块、铜块、下界合金块、紫水晶块、石英块、粗铁块、粗金块和粗铜块。
- 原版矿物块的装备组件指定为护腿槽；不再指定胸甲槽。

## 对应武器
- 穿上原版矿物块后，自动获得对应材质的专属矿物剑。
- 每种矿物剑拥有按矿物稀有度递增的耐久、伤害和附魔：锋利、抢夺、耐久、火焰附加按矿物等级组合。
- 背包满时，专属武器会掉落在玩家脚边；脱下矿物块时，已获得的武器保留在背包中；重新穿戴不会重复发放已有武器。
- 使用专属矿物剑成功命中生物时，每次命中掉落 1–2 个对应材料，另加武器对应的抢夺等级。
- 掉落的是物品而不是矿物块：铁锭、金锭、铜锭、下界合金锭；钻石、绿宝石、青金石、红石粉、煤炭、石英、紫水晶碎片及粗矿原料等掉落对应原版物品。

## 行走效果
- 原版矿物块穿在护腿栏时，仍会触发对应矿物行走效果。
- 旧存档中仍留在胸甲栏的矿物块，也会继续触发行走效果；新获得的矿物块穿戴位置是护腿栏。

## 版本
- Minecraft Java 26.2
- Fabric Loader 0.19.3
- Fabric API 0.155.2+26.2
- Java 25

安装时需同时安装对应版本的 Fabric Loader 和 Fabric API。
