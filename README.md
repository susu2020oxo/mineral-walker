# 矿物行走者：矿物化身 V3.0.1

V3.0.1 修复所有矿物护腿材质：使用原版 64×32 护腿 UV 结构生成各矿物对应的护腿纹理；不改动 V3.0.0 的穿戴、化身、地形、触碰转化、生命值 HUD 和武器效果。

Minecraft Java 26.2 / Fabric。

## 四槽原版矿物块穿戴
- 不注册矿物头盔、胸甲、护腿或靴子。
- 直接使用 Minecraft 原版矿物块物品，四个装备栏都可以穿戴。
- 支持煤炭块、铁块、金块、钻石块、绿宝石块、青金石块、红石块、铜块、下界合金块、紫水晶块、石英块、粗铁块、粗金块和粗铜块。
- 每个装备栏都使用原版的 minecraft:*_block 物品 ID。
- 右键第一块矿物块会装备到胸甲；之后背包里的矿物块会按胸甲、护腿、头盔、靴子的顺序切换到下一个空装备栏。

## 四件同种矿物触发完整化身
当头盔、胸甲、护腿、靴子四个位置全部装备同一种原版矿物块时：
1. 角色显示同材质的全套矿物化身装备外观。纹理包含金色参考图的红/紫双眼与青色胸前徽记，并按矿物材质换色。
2. 行走时将玩家周围 10×10 区域内可替换的实心地面变成对应矿物块。容器、流体、方块实体、空气和不可破坏方块会被保护。
3. 触碰到的生物会立即死亡，并在原地生成竖直堆叠的两块对应矿物块；如果位置没有足够空间，则掉落两块对应矿物块物品。其他玩家不受影响。
4. 玩家生命值心形 HUD 会变为对应矿物颜色。
5. 护腿对应的专属武器会获得强化附魔：高等级锋利、抢夺、耐久、火焰附加、经验修补和击退。

## 未集齐四件时
- 保留已有矿物行走基础效果。
- 护腿栏矿物块仍会发放对应矿物武器。
- 武器攻击生物仍会掉落对应矿物材料。

## 参考外观
以仓库中的金色方块角色参考图为设计方向；所有矿物共享同一套人物装备轮廓，只改变对应材质颜色和像素纹理。
