# 矿物行走者（Mineral Walker）V2.0

Minecraft Java 26.2 / Fabric 模组。

## 保留的 V1 功能
- 原版煤炭块、铁块、金块、钻石块、绿宝石块、青金石块、红石块、铜块、下界合金块、紫水晶块、石英块、粗铁块、粗金块、粗铜块直接作为胸甲穿戴。
- 穿着对应胸甲行走时，脚下的实心地面变成对应矿物块。

## V2 新功能
- 新增 14 种矿物护腿。胸甲仍然直接使用原版矿物块；护腿是新增的独立护腿物品，因为 Minecraft 的一个物品的 equippable 组件只能指定一个装备槽位。
- 穿上矿物护腿后，自动获得对应材质的专属矿物剑；背包满时武器会掉落在玩家脚边。
- 每种矿物剑拥有按矿物稀有度递增的耐久、伤害和附魔：锋利、抢夺、耐久、火焰附加按矿物等级组合。
- 使用专属矿物剑成功命中生物时，每次命中掉落 1–2 个对应材料，另加武器对应的抢夺等级；致命一击也会掉落。
- 掉落的是物品形态而非矿物块：铁锭、金锭、铜锭、下界合金锭；钻石、绿宝石、青金石、红石粉、煤炭、石英、紫水晶碎片及粗矿原料等则掉落对应原版物品。
- 脱下护腿时，已获得的武器保留在背包中；再次穿戴同一护腿不会重复发放已有武器。

## 版本
- Minecraft Java 26.2
- Fabric Loader 0.19.3
- Fabric API 0.155.2+26.2
- Java 25
