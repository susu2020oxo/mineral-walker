# 矿物行走者（Mineral Walker）V2.0.2

Minecraft Java 26.2 / Fabric 模组。

## 原版矿物块双槽穿戴
- 不注册任何矿物胸甲或矿物护腿物品。
- 直接使用 Minecraft 原版矿物块物品，可同时装备在胸甲栏和护腿栏。
- 每个装备栏需要一块原版矿物块；可以使用相同矿物块，也可以使用不同矿物块。
- 右键装备第一块矿物块时，默认进入胸甲栏；胸甲栏已有矿物块后，背包中的其他矿物块会自动切换为护腿栏穿戴组件，右键即可装备到护腿栏。
- 支持煤炭块、铁块、金块、钻石块、绿宝石块、青金石块、红石块、铜块、下界合金块、紫水晶块、石英块、粗铁块、粗金块和粗铜块。
- 通过每个物品堆栈独立的装备组件区分胸甲和护腿位置；物品 ID 仍是原版 minecraft:*_block，不添加新的矿物护甲物品。

## 双槽效果
- 胸甲栏的矿物块：激活对应矿物行走效果，走过的实心地面变成对应矿物块。
- 护腿栏的矿物块：自动获得对应材质的专属矿物剑。
- 胸甲和护腿可使用不同矿物；行走效果由胸甲决定，武器由护腿决定。

## 对应武器
- 每种矿物剑拥有按矿物稀有度递增的耐久、伤害和附魔：锋利、抢夺、耐久、火焰附加按矿物等级组合。
- 背包满时，专属武器会掉落在玩家脚边；脱下矿物块时，已获得的武器保留在背包中；重新穿戴不会重复发放已有武器。
- 使用专属矿物剑成功命中生物时，每次命中掉落对应材料。
- 掉落的是物品而不是矿物块：铁锭、金锭、铜锭、下界合金锭；钻石、绿宝石、青金石、红石粉、煤炭、石英、紫水晶碎片及粗矿原料等掉落对应原版物品。
