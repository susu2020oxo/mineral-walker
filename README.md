# 矿物行走者（Mineral Walker）

Minecraft Java 26.2 / Fabric 模组。

## 第二版设计
- 直接给原版矿物方块物品添加原版 `equippable` 数据组件；不注册独立矿物胸甲物品。
- 原版金块、钻石块、铁块、绿宝石块等可以放进胸甲栏，也可以右键穿戴。
- 穿戴时角色胸甲层显示对应矿物材质。
- 穿戴对应矿物块后，玩家每走到新的地面方块，脚下的实心方块就转换成该矿物块。
- 穿戴、切换、脱下时显示系统提示和快捷栏上方提示。
- 不替换空气、液体、容器/方块实体、不可破坏方块或没有坚实顶部的方块；普通地面和玩家建造的实心地板都会转换。

## 支持的原版方块物品
煤炭块、铁块、金块、钻石块、绿宝石块、青金石块、红石块、铜块、下界合金块、紫水晶块、石英块、粗铁块、粗金块、粗铜块。

## 版本
- Minecraft Java 26.2
- Fabric Loader 0.19.3
- Fabric API 0.155.2+26.2
- Java 25
